# 2026-08-06 · 최신순(LATEST) 목록 조회의 실행계획 채취

> **부하 테스트가 아니다.** 묻는 것이 "플랜이 어떻게 잡히는가"라서 `EXPLAIN ANALYZE`로 답한다
> ([가이드](../../../docs/perf/load-test-guide.md) 게이트 ①). 처리량·백분위는 **아무것도 주장하지 않는다.**
>
> 같은 날 채취한 인기순([`2026-08-06_place-stats-version-explain`](../2026-08-06_place-stats-version-explain/))과
> **같은 DB·같은 데이터·같은 파라미터**다. 케이스 10개가 1:1로 대응하므로 두 정렬을 나란히 읽을 수 있다.

## 1. 문제

인기순은 V29(버전 행)+V30(커버링 확장)으로 `place_stats` 단독 + 인덱스 하나가 됐고, 실측으로
동네 1개에서 **11행만 읽고 멈춘다**는 것이 확인됐다. 최신순은 그 전환의 대상이 아니었다 —
기준 테이블이 `places`로 남았고(신규 장소가 맨 앞에 와야 하므로 의도된 비대칭),
쓸 수 있는 인덱스는 `idx_places_town_active (town_id, active)` 하나뿐이다.

**정렬 축인 `created_at`이 그 인덱스에 없다.** V11이 "LIMIT 없는 전체 조회에서 filesort 비용
절감 효과가 없다"며 `idx_places_town_active_created`에서 `created_at`을 뺐는데, 그 판단은
커서 페이징이 붙기 전의 것이다. 게다가 이 경로에는 인기순엔 아예 없는 `place_stats` LEFT JOIN이
하나 달려 있다.

## 2. 원인 가설

정렬 축이 인덱스에 없으므로 최신순은 **모든 요청에서 filesort**를 하고, 정렬 입력은 페이지
크기가 아니라 **조회 범위의 활성 장소 수 전체**(동네 100 / 시 1,800)다. 커서를 줘도 술어가
인덱스 경계로 흡수되지 않아 읽는 양이 줄지 않는다. 여기에 LEFT JOIN이 정렬 **이전에** 수행되면
LIMIT 11짜리 요청이 `place_stats` PK 룩업을 1,800번 하게 된다.

## 3. 기술적 선택

**없다 — 이 캠페인은 진단이고 아무것도 고치지 않는다.** 인덱스를 더할지 말지는 이 채취가
비용의 모양을 보여 준 다음의 결정이다 (`findLatestRows` javadoc이 "이 정렬에 새 인덱스를
만들지 않는다"고 못 박아 둔 근거 — "정렬 대상이 1,800건 수준이라 싸다" — 가 커서·조인까지
포함해도 성립하는지가 쟁점이다).

## 4. 검증할 주장 (채취 전 사전 등록)

| # | 예상 | 반증되면 |
|---|---|---|
| ① | 태그가 없어도 **항상 filesort**이고 커버링이 아니다. 동네 1개에서 인기순은 11행에서 멈췄지만 최신순은 **100행 전부** 읽는다 | 인덱스 없이도 정렬이 만들어진다는 뜻 — 어떤 경로인지 규명 |
| ② | 커서 페이지가 첫 페이지보다 **싸지지 않는다**. `created_at` 술어가 range 경계로 흡수되지 못하고 사후 필터가 된다 | 옵티마이저가 다른 인덱스를 찾았다는 뜻 |
| ③ | **LEFT JOIN이 정렬 이전에 수행된다** — 시 단위면 LIMIT 11인데 `place_stats` PK 룩업이 1,800회 붙는다 | LIMIT 이후로 미뤄진다면 조인 비용은 페이지 크기에 비례 (문제 없음) |
| ④ | 버전 스칼라 서브쿼리 `(SELECT current_generation ...)`는 **상수 1회 평가**다 | 행마다 재평가면 심각 — javadoc의 "PK 1행이라 상수로 한 번만 평가한다"가 거짓 |
| ⑤ | 다중 태그에서 주도 테이블이 `place_tag`로 뒤집힌다. 단 **인기순만큼의 30배 악화는 나지 않는다** — 잃을 정렬 인덱스가 애초에 없다 | 인기순과 같은 배율로 나빠지면 플립 자체가 표적 |

## 5. 성공 조건

개선 캠페인이 아니므로 "성공"이 아니라 **판정**이다. 예상 다섯 개 각각을 충족/불충족으로
가르고, 불충족은 왜 빗나갔는지까지 적는다. 인기순과 대조 가능한 표를 남기는 것이 산출물이다.
