# 2026-07-31 · 하이브리드 점수 공식 — 명예 항의 필요성과 α 결정

> **부하 테스트가 아니다** (게이트 ① 판정): 트래픽·지연 주장이 없는 랭킹 품질 분석.
> 벤치 DB 위의 결정적 SQL 비교라 Artillery·호스트 정리가 불필요하다. 배치 소요 확인만 3회 곁들인다.
>
> 아래 다섯 항목은 **측정 전에 사용자 확정을 받았다 (2026-07-31).** 결과에 맞춰 수정하지 않는다.

## 1. 문제

현재 인기 점수는 순수 감쇠 합이라 점수가 누적 총량이 아니라 **최근 유입 속도**에 수렴한다.
오래 사랑받은 장소가 최근 반짝 장소에 밀릴 수 있다. 단, 지금까지 인용된 "누적 69,784건이
최근 2,000건에 2.5배로 진다"는 **가정 분포 위의 예시이지 실측이 아니다** — 문제의 실재부터
실제 시드 분포(북마크 1,039만)에서 확인한다.

## 2. 원인 가설

반감기 감쇠 합은 정상상태에서 `일일 유입 r × 90/ln2 ≈ r × 130`에 수렴한다 (등비 합).
3년 전 북마크의 잔존 가중치는 `0.5^12 ≈ 0.02%`라 누적 총량이 항에서 소거된다.

## 3. 기술적 선택

명예 항 추가 하이브리드:

```
score = α·ln(1 + bookmark_count)          ← 감쇠 없음 (누적 명예, ln 압축)
      + β·Σ북마크[0.5^(age/90)]           ← 현행 모멘텀 항 (β=1.0)
      + γ·Σ리뷰[(rating−3)·0.5^(age/90)]  ← 현행 리뷰 항 (γ=3.0)
```

후보 α ∈ {0(현행), 50, 100, 300}. 대안인 멱함수 감쇠 `(1+age)^-k`는 항이 하나라 단순하지만
명예/모멘텀을 독립 조절할 수 없다 — 이번 측정으로 기각 사유까지 확정한다.

## 4. 검증할 주장

실제 1,039만 건 분포 위에서:

- (a) 현행 공식(α=0)이 누적 상위 장소를 Top-50 밖으로 실제로 밀어내는가 — **문제 실재**
- (b) α 후보 각각에서 누적 명문 생존과 트렌딩 진입이 균형을 이루는 지점이 있는가
- (c) ln 항 추가가 배치 소요를 유의미하게 늘리지 않는가

## 5. 성공 조건 (사전 등록 — 2026-07-31 사용자 확정)

**평가 대상 4곳**: 북마크 상위 leaf 3곳(강남·홍대합정·건대성수) + 서울 시 단위(leaf 합집합).

1. **문제 실재 게이트**: 대상별로 "누적 북마크 상위 10 장소 중 현행 Top-50 탈락 수"를 세고,
   **과반(6곳 이상) 탈락이 4개 대상 중 2곳 이상**이면 문제 실재 → α 평가 진행.
   미달이면 **"현행 유지"가 결론** — 역방향 결론도 이 캠페인의 성공이다.
2. **α 채택 조건** (전부 만족하는 α 중 **최솟값** 채택 — 상위권 굳힘을 최소화):
   - (i) 누적 상위 10의 Top-50 잔존 ≥ 5곳 (대상 4곳 각각)
   - (ii) 트렌딩 보존: 현행(α=0)에서 Top-50에 드는 트렌딩 장소 수 대비, 해당 α에서 그 수가
     **절반 밑으로 떨어지지 않음**
   - (iii) 강건성: 채택 후보 α*에 대해 α*/2·α*×2의 Top-50 겹침률이 급변하지 않음
     (겹침 40곳 이상 유지)
3. **배치 비용**: ln 항 추가 후 배치 소요가 기존 **6,049ms 대비 ±10% 이내** (3회 중앙값).

> 판정 규칙 중 "2곳 이상"·"겹침 40곳"은 확정된 조건("과반"·"급변하지 않음")의 사전
> 조작화(operationalization)로, 측정 전에 등록한다. 경계선 결과는 조정하지 말고 사용자에게 보고한다.

## 이 측정으로 말할 수 없는 것 (미리 명시)

- 벤치 시드는 인공 분포(Zipf + 트렌딩 20곳 주입)다. **α의 최종 미세 조정은 운영 데이터에서 다시 본다.**
- `avg_rating` 저평점 게이트는 리뷰 시드가 인공이라 이번엔 판정하지 않는다.
- 랭킹 "품질"의 최종 심급은 사용자 반응이지 겹침률이 아니다 — 이 측정은 공식의 **성질**을 확인한다.

## 결과

**결론: 명예 항을 추가하지 않는다 (현행 α=0 유지).** 단 근거는 "α가 무익하다"가 아니라
**"이 데이터로는 α의 효용을 판정할 수 없다"**이다.

→ 전문: [`docs/perf/2026-07-31-hybrid-score-formula.md`](../../../docs/perf/2026-07-31-hybrid-score-formula.md)

| 사전 등록 조건 | 실측 | 판정 |
|---|---|---|
| 1. 문제 실재 게이트 (과반 탈락 대상 ≥ 2곳) | 4개 대상 **전부 탈락 0곳** — 누적 상위 10이 현행에서 1~18위 | **미달 → 현행 유지** |
| 2. α 채택 (i)(ii)(iii) | α=50/100/300 모두 만족하나 **Top-50 집합이 현행과 100% 동일** | 채택할 α 없음 |
| 3. 배치 비용 ±10% | 현행 5,894.73ms / ln 추가 5,876.92ms → **−0.30%** (회차 편차 1.0%보다 작다) | **통과** |

핵심 원인: 비트렌딩 5,980곳의 `momentum / bookmark_count`가 **0.294~0.424(σ=0.020)로 사실상 상수**다.
시드가 장소별 유입률을 548일 내내 시간 불변으로 뒀기 때문에 `ln(1+c)`와 `0.358c`가 같은 c의
단조증가 함수가 되고, 그러면 어떤 양의 조합도 같은 순위를 낸다 —
**α=100,000까지 밀어도 Top-50이 최대 3곳만 바뀐다.**

즉 명예 항이 해결하려는 "과거에 사랑받았으나 지금 유입이 끊긴 장소"가 이 시드에 **한 곳도 없다.**
재판정의 단일 조건은 운영 데이터에서 이 비율의 분포 폭이 실제로 넓은지 확인하는 것이다.
